Claude paper trading setup for Indian and US markets

We connected Claude to a paper trading engine. Press Start and Claude reads live prices, decides BUY, SELL or HOLD with a written reason, and a simulator fills the call with realistic costs. Virtual money only. Below is how it works, then a step-by-step setup you can follow tonight.

How one decision works

Claude decides. Code executes.

Claude never touches the account directly. It reads a market snapshot and answers in a fixed format. Everything after that, from position size to stop-loss to the closing bell, is plain code that behaves the same way every time.

  1. every 30 s

    Watch prices

    Pull 5-minute candles for the watchlist and check open stops and targets on every poll.

  2. every 15 min

    Build a snapshot

    Price, VWAP, RSI, opening-range high and low, volume vs average, plus cash and open positions.

  3. ~10 s

    Ask Claude

    Snapshot goes to Claude Code on your own login. Claude replies with an action, size, stop and a reason.

  4. instant

    Check the rules

    Code enforces max positions, max 20% per stock, cash, the entry cutoff and the daily loss limit.

  5. fresh price

    Fill and journal

    Fill at the price after Claude answered, with spread, slippage and real fees. Every call is saved.

What Claude sends back

A trade with a reason, every time

The reply is structured, so the engine can read it and you can audit it later. If Claude's answer is malformed or breaks a rule, the engine treats it as HOLD. A bad answer can never turn into a bad trade.

{
  "market_view": "SPY holding its opening-range
     low; tech leading.",
  "decisions": [{
    "symbol": "GOOGL",
    "action": "BUY",
    "allocation_pct": 10,
    "confidence": 0.7,
    "stop_loss_pct": 1.5,
    "target_pct": 3.0,
    "reason": "Reclaimed VWAP on 1.8x
       volume, RSI 58 and rising."
  }]
}
Technical insights

Small details that keep paper results realistic

The price moves while Claude thinks

A decision takes about 10 seconds. The engine fetches a fresh price after the answer and fills against that, so a ₹1,500 signal can fill at ₹1,500.60. Paper trading that fills at the signal price looks better than real trading ever will.

Spread, slippage and market impact

Each fill crosses half of a 4 bps spread, adds 3 bps slippage and pays extra when it takes a large share of the candle's volume. It never fills more than 5% of a bar.

Replay without looking ahead

Practice mode replays a real past session on a virtual clock. Claude only sees candles that had closed at that moment, and orders fill on the next bar, about 60 seconds later.

Real money is blocked in code

Only market-data addresses are allowed out. Broker order URLs and trading SDKs are blocked on import, and the app refuses to start if paper_only is turned off.

Your Claude login, no API key

The app runs Claude Code in the background with claude -p and no tools enabled. It uses your Pro or Max plan, so there is no separate API bill.

Many agents, one database

Each agent is its own Claude process with its own style, model, money and watchlist. They all write to one SQLite journal in WAL mode, so they can run side by side and land on one leaderboard.

How much of your plan it uses

One call every 15 minutes is 26 calls per US session (6.5 h) and 25 per NSE session (6.25 h). Three agents means about three times that. Haiku is the lightest model to run extra agents on.

Intraday by default

Every position is closed before the bell: 15:15 IST on NSE, 15:50 ET in the US. A 3% daily loss closes everything and stops new entries for the rest of the day.

Free market data, with a lag

Prices come from Yahoo Finance at no cost and can trail the exchange by a few minutes. For NSE you can switch to the official Upstox API, which is free with an Upstox account.

Costs the simulator charges

Real fee schedules, both markets

Small trades lose more to fees than people expect. The engine applies these on every simulated fill, so the P&L you see is after costs.

Setup guide · Week One

Run Claude's paper trading desk on your computer

From download to Claude's first call in about 5 minutes. The launcher installs everything it needs and asks before each install.

What you need Install First run Start trading Agents Settings Troubleshooting

What you need

A computerWindows 10/11, macOS or Linux. Leave it awake during market hours.
Claude Pro or MaxClaude trades on your own Claude login. No API key needed.
InternetFor live prices and Claude. Market data is free from Yahoo Finance.
No broker accountEverything is virtual. The app cannot place real orders.

Install

  1. Download the code

    Open the GitHub page, click the green Code button, then Download ZIP. Unzip it anywhere, for example your Desktop.

    Open GitHub →

    Or with git:

    git clone https://github.com/akshaymshankar/Breaking_Money_Trading-Agent.git

  2. Double-click START-TRADING.bat

    If a blue Windows protected your PC box appears, click More info, then Run anyway. It shows up because the file came from the internet.

  3. Right-click start-trading.command → Open

    Use right-click the first time so macOS lets it run. After that, a normal double-click works. If macOS still refuses, run this in Terminal from the folder:

    chmod +x start-trading.command setup.sh

  4. Run the launcher

    Open a terminal in the folder and run:

    ./start-trading.command

  5. Answer the setup questions

    A window opens and walks through four checks. Type Y and press Enter when it asks to install something.

What the first run does

  1. Python

    Looks for Python 3.11 or newer. If it is missing, it offers to install it (Windows Package Manager on Windows, Homebrew on Mac) or opens python.org.

  2. App packages

    Installs pandas, yfinance and the rest into a private .venv folder inside the app, so nothing else on your computer changes. Takes 1 to 3 minutes, once. If a package ever breaks, the next launch repairs it on its own.

  3. Claude Code

    If Claude Code is missing, it offers the official installer from claude.ai. Then your browser opens so you can sign in with your Claude account. The app never sees your password.

  4. Control panel

    The app opens in your browser at http://127.0.0.1:8787. Keep the black window open while you use it. Closing that window quits the app.

Next time the same double-click opens the app in a few seconds. Setup only runs once.

Start trading

  • Pick a market with the United States / India switch at the top of the Trade screen. United States is the default.
  • Check the Claude card at the bottom of the sidebar. Green means connected. If it says Sign in with Claude or Install Claude Code, press it and follow the window that opens.
  • Press Start. During market hours Claude starts trading right away. Its calls and reasons appear under Claude's reasoning, and its buys and sells are marked on the chart.
  • Market closed? Start arms Claude for the next open. To see it work right away, press Practice on the last session, which replays the most recent real trading day.
  • Stop any time. Start again later and it resumes the same challenge with the same cash and positions.

Run several agents

Open the Agents screen. Each agent is its own Claude with its own money, watchlist, market and model.

  • Spawn squad of 3 creates three different styles in one click.
  • Or pick a style: Momentum, Mean Reversion, Breakout, Risk Guardian or Index. You can also write your own in plain English.
  • Choose Live to trade today's market or Replay to practice on a past session.
  • The leaderboard ranks every agent by return after costs.
Plan limits: each agent asks Claude once per decision interval, so three agents use your plan about three times as fast. Choose Haiku for extra agents.

Troubleshooting

Packages failed to install

Check your internet connection and double-click the launcher again. It repairs a broken install by itself. If it still fails, delete the .venv folder inside the app and try once more.

The Claude card says "not signed in"

Press Sign in with Claude in the sidebar, finish the sign-in in your browser, and come back. The card turns green on its own within a few seconds.

I pressed Start and nothing is happening

The market is probably closed, so Claude is waiting for the open. Use Practice on the last session to see it trade now.

No prices on the chart

Yahoo Finance is briefly unavailable or the market has been closed for a while. Try Practice, or check again during market hours.

"Port already in use"

An older copy of the app is still running. Close every old Arena window. The app also picks the next free port and prints the address in the black window.

Can this place real trades?

No. Order addresses and broker trading libraries are blocked in code, and the app refuses to start if paper-only mode is turned off.
