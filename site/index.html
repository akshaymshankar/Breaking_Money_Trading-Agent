Setup guide

Live in 4 steps

About 5 minutes. No coding.

1

Download

On GitHub: Code → Download ZIP, then unzip.

Open GitHub ↗
2

Double-click

Open START-TRADING.bat. If Windows warns you: More info → Run anyway.

Right-click start-trading.command → Open. Only the first time.

./start-trading.command

It installs what's needed and asks before each install.

3

Sign in to Claude

Your browser opens. Sign in with your Claude Pro or Max account. No API key.

4

Press Start

Market closed? Press Practice on the last session. India is always practice, on prices more than 30 days old.

That's it. Claude is paper trading.

Quick answers

Stuck?

Install failed

Check your internet and double-click again. It repairs itself.

Claude says "not signed in"

Press Sign in with Claude in the app's sidebar.

Pressed Start, nothing happens

The market is closed. Use Practice on the last session.

Can it place real trades?

No. Real orders are blocked in the code.
